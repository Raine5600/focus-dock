FOCUS DOCK — NOTION FORMULA REFERENCE (COPY-PASTE)
==================================================

Create these as Formula properties in the [TODAY] Today database.
Property names must match exactly — the view filters depend on them.

-------------------------------------------------------------------------------
HIDE SEQUENCE (Formula)
-------------------------------------------------------------------------------
Property name: Hide Sequence
Type: Formula

Paste this formula:

if(empty(prop("Task Before")), false, if(prop("Before Done") > 0, false, if(prop("Due") < prop("Before Due"), false, true)))

What it does:
Hides a sequenced task while its predecessor is unfinished.
Tasks with no Task Before always show.

-------------------------------------------------------------------------------
HIDE (Formula)
-------------------------------------------------------------------------------
Property name: Hide
Type: Formula

Paste this formula:

prop("Hide Sequence")

What it does:
Pass-through used by the Do This Next view filter (Hide is unchecked).
Filter on Hide, not on Hide Sequence directly.

-------------------------------------------------------------------------------
REQUIRED ROLLUPS (create before the formulas)
-------------------------------------------------------------------------------
• Before Done — Rollup: relation Task Before → property Done →
  Calculate: Checked (count of checked)
• Before Due — Rollup: relation Task Before → property Due →
  Calculate: Latest date

-------------------------------------------------------------------------------
DO THIS NEXT VIEW
-------------------------------------------------------------------------------
• Filter: Hide is unchecked
• Filter: Done is unchecked
• Sort: Due ascending

>> If too many tasks show: verify the Hide Sequence formula exists and the
   view filters on Hide, not Hide Sequence directly.
