Full remaster of `private/downloads/Focus_Dock_ADHD_Notion_Recovery_Guide.pdf`
(41 pages, generated by `scripts/generate_pdf.py`). Cover art refreshed via
`scripts/generate_cover.py` (Version 2.0).

## Why (audit findings in v2)

### Accuracy bugs
1. **Content overprinted the cover** — the story started on page 1, so Lane 1
   text rendered on top of the cover PNG.
2. **Every footer said "LANE 5 — REFERENCE"** — `doc.current_lane` was set at
   story-build time; by render time it always held the last lane.
3. **Broken find/replace artifacts** from stripping minute-promises:
   "Reset feels complete enoughutes", "too long on aesthetics, zero tasks
   completed", "Notion time under minimal time/day".
4. **Stale v1 pointers** — "Print Part 15", "Part 10", "Part 2" referenced
   sections that no longer exist.
5. **Unresolvable cross-references** — text pointed to "R-13 FAQ" etc., but no
   reference section carried an R-number.
6. **Duplicate steps** in Lane 2's DO THIS NOW ("Do it now — phone in another
   room" + "Do the shrunk task. Phone in another room.").
7. **Outdated Notion UI instructions** — "/table → Full page", "Settings &
   members → Homepage", "two-way relation".

### Design problems
- Callout boxes split across page boundaries; ~8 pages half/mostly empty
  (42 pages, poorly filled); no lane progress indicators; ANCHOR boxes missing
  the TIME field required by `research/02-adhd-pdf-design-spec.md`.

## What changed in v3

### Architecture (`generate_pdf.py`)
- `FocusDockDoc(SimpleDocTemplate)` draws footers in `afterPage()`; invisible
  `LaneMarker` flowables update lane state **at draw time**, so every footer
  shows the correct `LANE N OF 5 — NAME` plus a 5-segment mint progress bar.
- Cover art gets a dedicated page 1 (blank story page under the PNG).
- All callout boxes wrapped in `KeepTogether`; section headings glued to their
  first block. **Gotcha found:** nesting a `KeepTogether` inside another forces
  a page break before the group every time — `emit_blocks(..., wrap_boxes=False)`
  is used when blocks are nested into the section-header KeepTogether.
- Rounded-corner callouts, R-number chip headings, refreshed lane banners
  (eyebrow "LANE N OF 5" + subtitle + coral rule), zebra data tables via a
  single `data_table()` helper.

### Content
- ANCHOR boxes now carry TIME estimates. Soft framing only ("~45–60 min, one
  sitting", "~10 min, hard stop at 15") — consistent with `lib/product.ts`,
  which deliberately avoids the old "47-minute" promise.
- Lane 2 renamed "THE 5-MINUTE WIN"; install split into Steps 1–5 with per-step
  ANCHOR / DO THIS NOW / CHECKPOINT / IF YOU DRIFT (per blueprint 3.1–3.5).
- Reference lane numbered **R-1..R-16 in blueprint order** with a "Find it
  fast" index; Common Mistakes merged into R-6 Troubleshooting (dedupe).
- All typos and stale pointers fixed; every in-text R-N pointer now resolves.
- Notion UI updated to the current interface: "/database → Database — Full
  page", relations with "Separate directions", rollup "Calculate: Checked",
  "Open on start → Top page in sidebar" (with a menus-move hedge in R-2).
- Lane 1 gains a visual system map (3 database cards → HOME); R-8 emergency
  card restyled as a cut-out card with dashed cut lines; R-16 is a composed
  closing page.
- Deviation from blueprint noted: the two formulas stay inline in Install
  Step 3 (plus full breakdown in R-1) so the install remains one-sitting
  self-contained; blueprint wanted pointers only.
- "⚠" replaced with "!" in drift labels — base-14 Helvetica renders U+26A0 as
  a tofu box.

### Companion files
- `private/downloads/Focus_Dock_Formulas.txt` synced to R-1 wording.
- `assets/focus_dock_cover.png` regenerated: drawn check circles (no "[OK]"
  tokens), 5-segment dock motif in the band, card shadow, "Version 2.0 ·
  July 2026".

# Addendum: Version 2 — July 15, 2026

Separate deliverable, does not touch Version 1:
- `private/downloads/Focus_Dock_ADHD_Notion_Recovery_Guide_v2.pdf` (43 pages)
- `scripts/generate_pdf_v2.py` + `scripts/generate_cover_v2.py`
- `assets/focus_dock_cover_v2.png`

## Changes over Version 1
1. **"Lane" → "Section"** everywhere (banners, footers, pointers, picker table).
2. **New cover**: full-bleed navy design — dot-grid texture, corner accents,
   card-stack illustration of the "one visible task" promise, feature chips,
   five-segment dock motif, "Version 2".
3. **Contents page (p. 2)** with real page numbers via a two-pass build:
   pass 1 records where every tagged heading lands (`doc.toc_pages`, filled in
   `afterFlowable`), pass 2 rebuilds with the numbers. Placeholder and final
   tables share identical widths/row counts so pagination is stable.
   **Gotcha:** `KeepTogether` dissolves into its children before
   `afterFlowable` fires — TOC tags must go on the inner heading flowable,
   never the wrapper.
4. **R-index ("Find it fast") now shows page numbers** for R-1..R-16.
5. **Readability layer** (the v1 copy was telegraphic): box legend on the
   Contents page; an intro paragraph under every section banner; a purpose
   sentence before each install step's action box; a daily-loop explainer in
   Daily Use; "Up next →" transitions at the end of Sections 1–4.

## Verification
- TOC section pages and R-1/R-6/R-8 quick-jump numbers verified against the
  actual heading positions in the built PDF.
- 0 remaining "lane" words; 0 banned terms; 0 placeholder page numbers.
- v1 file and main PDF byte-identical (md5) — Version 1 untouched.

## Regenerate v2

```bash
python3 scripts/generate_cover_v2.py

```
